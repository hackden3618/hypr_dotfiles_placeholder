# Profiles

Profiles describe operating modes for the workstation. They are data contracts, not random shell snippets.

- `minimal`: conservative baseline
- `development`: daily engineering mode
- `workstation`: full default platform
- `performance`: low-latency focused work
- `battery`: laptop efficiency
- `presentation`: quiet notifications and predictable visuals
- `gaming`: minimal compositor overhead

Future profile activation should read these files and apply changes through capability-level adapters.
