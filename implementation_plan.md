# ATLAS Workstation Engineering Platform
## Master Implementation Plan — v2 (Revised)

> **Repository:** `~/.config/hypr`
> **Current State:** JaKooLit Hyprland-Dots fork — functional but architecturally scattered, legacy `.conf` format
> **Target State:** A professionally engineered Linux Engineering Platform running on Hyprland's native Lua configuration
> **Date:** 2026-06-28
> **Scope:** Full architectural redesign + Lua migration, zero functional regressions

---

## Key Decisions (Resolved)

| Decision | Resolution |
|---|---|
| `awww-daemon` vs `swww-daemon` | ✅ **`awww-daemon` is correct** — swww was officially renamed to awww. All references to `swww` in scripts need updating. |
| Monitor configuration authority | ✅ **nwg-displays only** — `hyprland-gui.conf` monitor line removed. Monitors managed via `desktop/monitors/monitors.lua` generated by nwg-displays. |
| Script directory merge | ✅ **Full merge** — `scripts/` + `UserScripts/` consolidated into single `automation/` tree |
| Config format | ✅ **Lua-first** — migrate to `hyprland.lua` (Hyprland 0.55+). Legacy `.conf` kept only for nwg-displays-generated monitors (pending nwg-displays Lua support) |
| HyprMod | ✅ **Keep as optional GUI** — HyprMod is compatible with Lua configs. It may be used for exploration but its `hyprland-gui.conf` override file is **retired**. All settings live in the Lua module tree. |
| Vendor layer | ✅ **Absorb and eliminate** — The `configs/` vendor layer from JaKooLit is fully absorbed. No more vendor/user split. |

## Audit: What Exists Today

### Structural Problems

| Problem | Evidence |
|---|---|
| **Legacy `.conf` format** | Entire repo uses hyprlang syntax, deprecated in Hyprland ≥0.55 |
| **Dual config split with no clear ownership** | `configs/` (vendor) vs `UserConfigs/` (user) — both contain keybinds, startup, window rules |
| **Duplicate variable definitions** | `$mainMod`, `$scriptsDir` defined in both `configs/Keybinds.conf` AND `UserConfigs/UserKeybinds.conf` |
| **Duplicate and backup files in VCS** | `WindowRules-old.conf`, `WindowRules.conf.bak`, `WindowRulesDeprecated.conf`, `UserScripts.bak/` |
| **Two parallel script directories** | `scripts/` (50 files) + `UserScripts/` (15 files) + `UserScripts.bak/` = 3 overlapping script trees |
| **Application-centric naming** | `hyprmod/`, `wallust/`, `Monitor_Profiles/` — organized by tool, not by responsibility |
| **HyprMod override conflicts** | `hyprland-gui.conf` silently overrides opacity, rounding, dim_strength set in `UserDecorations.conf` |
| **Hardcoded username** | `source = /home/admin/.config/hypr/hyprland-gui.conf` — not portable |
| **stale `swww` references** | `WallustSwww.sh`, `swww query`, `swww img` calls throughout scripts — awww renamed the binary |
| **Dead code proliferation** | NixOS polkit script on Arch, Ubuntu nm-tray on Arch, KooLsDotsUpdate.sh, RainbowBorders.bak.sh |
| **Monolithic window rules** | 672-line `WindowRules.conf` with no internal structure |
| **Zero documentation** | `README.md` is 31 bytes |
| **Duplicate scripts** | `privacyIcons.sh` + `privacy_dots.sh` appear in both `scripts/` and `UserScripts/`; `Tak0-Autodispatch.sh` duplicated |

## Lua Architecture Design

### Entry Point: `hyprland.lua`

The entry point is **pure routing** — no configuration logic lives here:

```lua
-- ============================================================
-- ATLAS Workstation Engineering Platform
-- Compositor Entry Point
-- See: docs/ARCHITECTURE.md | docs/LUA_MIGRATION.md
-- ============================================================

-- Bootstrap first-boot initialization
hl.exec_once(os.getenv("HOME") .. "/.config/hypr/automation/boot/initial-setup.sh")

-- Load all platform modules
require("config.init")
```

### Module Loader: `config/init.lua`

```lua
-- ============================================================
-- ATLAS Platform — Module Loader
-- Load order matters: platform → desktop → input → startup
-- ============================================================

-- ── Platform Layer (dependencies for everything else) ───────
require("config.platform.variables")
require("config.platform.environment")
require("config.platform.input")

-- ── Desktop Layer ───────────────────────────────────────────
require("config.desktop.compositor.general")
require("config.desktop.compositor.decorations")
require("config.desktop.compositor.misc")
require("config.desktop.compositor.animations")   -- loads active profile

-- ── Window Rules ────────────────────────────────────────────
require("config.desktop.rules.tags")
require("config.desktop.rules.floating")
require("config.desktop.rules.opacity")
require("config.desktop.rules.workspace")
require("config.desktop.rules.layer")

-- ── Display ─────────────────────────────────────────────────
-- monitors.conf is sourced via hl.source() because nwg-displays writes .conf format
hl.source(os.getenv("HOME") .. "/.config/hypr/config/desktop/monitors/monitors.conf")
require("config.desktop.monitors.workspaces")

-- ── Theming (colors generated by wallust — .conf format) ────
hl.source(os.getenv("HOME") .. "/.config/hypr/config/desktop/theming/colors.conf")

-- ── Input / Keybinds ────────────────────────────────────────
require("config.input.keybinds.core")
require("config.input.keybinds.media")
require("config.input.keybinds.desktop")
require("config.input.keybinds.user")
require("config.input.devices.laptop")

-- ── Startup ─────────────────────────────────────────────────
require("config.startup.core")
require("config.startup.desktop")
require("config.startup.user")

-- ── Plugins ─────────────────────────────────────────────────
-- hyprexpo plugin config (stays .conf until plugin ecosystem adopts Lua)
hl.source(os.getenv("HOME") .. "/.config/hypr/plugins/hyprexpo.conf")
```

```lua

-- Window management, workspaces, system controls.
-- Do NOT add user-specific binds here — use user.lua.
-- ============================================================

local mod = USER.mainMod

-- ── Window Management ───────────────────────────────────────

hl.bind(mod .. " SHIFT + F",     hl.dsp.fullscreen(0))
hl.bind(mod .. " CTRL + F",      hl.dsp.fullscreen(1))
hl.bind(mod .. " + SPACE",       hl.dsp.togglefloating())
hl.bind("CTRL ALT + Delete",     hl.dsp.exit())

-- ── Focus ───────────────────────────────────────────────────
hl.bind(mod .. " + left",        hl.dsp.movefocus("l"))
hl.bind(mod .. " + right",       hl.dsp.movefocus("r"))
hl.bind(mod .. " + up",          hl.dsp.movefocus("u"))
hl.bind(mod .. " + down",        hl.dsp.movefocus("d"))

-- ── Move Windows ────────────────────────────────────────────
hl.bind(mod .. " CTRL + left",   hl.dsp.movewindow("l"))

hl.bind(mod .. " CTRL + up",     hl.dsp.movewindow("u"))
hl.bind(mod .. " CTRL + down",   hl.dsp.movewindow("d"))

-- ── Workspaces ──────────────────────────────────────────────
for i = 1, 10 do
  local key = i == 10 and "0" or tostring(i)
  hl.bind(mod .. " + " .. key,           hl.dsp.workspace(i))
  hl.bind(mod .. " SHIFT + " .. key,     hl.dsp.movetoworkspace(i))
  hl.bind(mod .. " CTRL + " .. key,      hl.dsp.movetoworkspacesilent(i))
end

-- Workspace scroll
hl.bind(mod .. " + mouse_down",   hl.dsp.workspace("e+1"))
hl.bind(mod .. " + mouse_up",     hl.dsp.workspace("e-1"))
hl.bind(mod .. " + period",       hl.dsp.workspace("e+1"))
hl.bind(mod .. " + comma",        hl.dsp.workspace("e-1"))
hl.bind(mod .. " + Tab",          hl.dsp.workspace("m+1"))
hl.bind(mod .. " SHIFT + Tab",    hl.dsp.workspace("m-1"))

-- ── Groups ──────────────────────────────────────────────────
hl.bind(mod .. " + G",            hl.dsp.togglegroup())
hl.bind(mod .. " CTRL + Tab",     hl.dsp.changegroupactive())

-- ── Master Layout ───────────────────────────────────────────
hl.bind(mod .. " + I",            hl.dsp.layoutmsg("addmaster"))
hl.bind(mod .. " CTRL + D",       hl.dsp.layoutmsg("removemaster"))
hl.bind(mod .. " CTRL + Return",  hl.dsp.layoutmsg("swapwithmaster"))

-- ── Mouse ───────────────────────────────────────────────────
hl.bind_mouse(mod .. " + mouse:272", hl.dsp.movewindow())
hl.bind_mouse(mod .. " + mouse:273", hl.dsp.resizewindow())

-- ── Special Workspace ───────────────────────────────────────
hl.bind(mod .. " SHIFT + U",     hl.dsp.movetoworkspace("special"))
hl.bind(mod .. " + U",           hl.dsp.togglespecialworkspace())
```

### Phase 3 — Automation Platform (Script Migration)

**Goal:** Consolidate all 65+ scripts from `scripts/` + `UserScripts/` into categorized `automation/` tree.

#### Shared Library: `automation/lib/common.sh`

Created first — all migrated scripts will source this:

```bash
#!/usr/bin/env bash
# ============================================================
# ATLAS Platform — Automation Common Library
# Source: source "$(dirname "${BASH_SOURCE[0]}")/../lib/common.sh"
# ============================================================
set -euo pipefail

readonly ATLAS_ROOT="$HOME/.config/hypr"
readonly AUTOMATION="$ATLAS_ROOT/automation"
readonly ICONS_DIR="$HOME/.config/swaync/icons"
readonly CACHE_DIR="$HOME/.cache/atlas"
readonly WALLPAPER_CURRENT="$ATLAS_ROOT/config/desktop/theming/.wallpaper_current"
readonly WALLPAPER_EFFECTS_DIR="$ATLAS_ROOT/config/desktop/theming"

# Logging
log()     { printf '[ATLAS] %s\n'       "$*" >&2; }
log_err() { printf '[ATLAS ERROR] %s\n' "$*" >&2; }

# Notification with deduplication key
notify() {
  local title="${1:?}" body="${2:-}" icon="${3:-dialog-information}" key="${4:-atlas}"
  notify-send -e -u low \
    -h "string:x-canonical-private-synchronous:${key}" \
    -i "$icon" "$title" "$body"
}

# Check if a command exists
require() {
  command -v "$1" >/dev/null 2>&1 || {
    log_err "Required command not found: $1"
    exit 127
  }
}

is_running() { pidof "$1" >/dev/null 2>&1; }

mkdir -p "$CACHE_DIR"
```

## Migration Safety Rules

1. **Never delete a file until its replacement is verified working** — use `git mv` for all moves
2. **Update ALL script path references** before deleting old paths
3. **Test `hyprctl reload`** after each phase — any parse error means a problem
4. **One phase per git commit** — atomic, reviewable history
5. **`awww` references** — audit all scripts with `grep -r "swww" ~/.config/hypr/` after Phase 1
6. **Monitor config** stays `.conf` (nwg-displays limitation) — source via `hl.source()` in `config/init.lua`
7. **wallust colors** stays `.conf` (wallust writes conf templates) — source via `hl.source()` in `config/init.lua`
8. **hyprlock and hypridle** configs stay `.conf` — they are standalone daemons, not Hyprland config
9. **hyprexpo plugin** stays `.conf` until Hyprland plugin ecosystem catches up with Lua
