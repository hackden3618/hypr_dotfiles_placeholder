# Desktop Platform

The desktop platform owns graphical capabilities. Applications are adapters.

Current capabilities:

- compositor
- launcher
- statusbar
- notifications
- clipboard
- wallpapers
- screenshots
- screenrecording
- widgets
- lockscreen
- idle
- animations
- theming

Hyprland, Waybar, Rofi, SwayNC, and Hyprlock are current implementations, not the architecture itself.
